# 说在前面

EdgeOne是我一直在使用的工具，作为前端部署也是符合我的使用需求的。

我也从未为此产品付费，因为免费就足以满足我的需求了。

最近我发现了我的网站持续被人通过其他路径访问，且访问的路径均不存在。我也因此发布了[一篇文章](https://blog.3mua.cn/post/1791552376540/)。当时我以为只是爬虫在爬取我的网站，就没有放在心上。直到我最近发现了其不对之处。

# 是谁在访问？

当时我发现，其访问URL均指向：https://eop-site-sh-prod-maz-1256816668.cos.ap-shanghai.myqcloud.com/

也就是上传至了腾讯云OSS，我以为是哪个自动程序在扫描其他人网站然后全部爬取上传至OSS。然后我通过他访问的路径也可以访问获取到我网站同路径内容。就把其目的归于自己克隆下来进行网站的发布，但是用途却不知。

这里有个很重要的点，就是其后台路径显示为腾讯云OSS，而OSS默认是访问后下载的。所以是通过其他方法访问的网站。

但是方法不知道，用途也不知道。我只知道我网站的内容被全部上传至了这个OSS内容，包含网页，图片，所有内容。且访问人数奇多。

# 数据从哪里来？

于是我开始好奇，为什么能获取到我的网站所有数据呢？

我对于其访问路径进行分析：/index-dpxxxxxx/index.html

于是我发现其为EdgeOne平台的网站昵称（index）与部署ID（dpxxxxxx）

也就是说，这个OSS为EdgeOne平台的OSS内容，用途是存储部署后的产物。

其最终应该是用来供用户访问的，不过不知道为什么会直接通过OSS的域名访问，这也就把域名暴漏给我了。

于是我在项目上传了一个17M大小的图片，通过正常链接访问是限速的：

https://3mua.cn/imgs/1791622356426.JPG

但是如果你通过OSS访问，是不限速的：

https://eop-site-sh-prod-maz-1256816668.cos.ap-shanghai.myqcloud.com/index-dpa8u7h3jacn/imgs/1791622356426.JPG

不过最大只能上传25M的文件，不然我高低用来做下载站了。

# 数据用来做什么？

不过依旧无法解释为什么有人能够通过链接直接访问？也许是腾讯云OSS的一些设置，也或许是其内部开发的一些工具来审计或者用于自我训练。

我们无从得知。
